버전 0.1.0 · 약 80MB · Windows 10 이상

내려받기가 막혔다면

오집!은 아직 코드 서명을 받지 않아서, 브라우저가 “흔히 다운로드되는 파일이 아닙니다”라며 막는 경우가 있습니다. 바이러스가 아니라 서명이 없어서 생기는 경고입니다.

크롬 · 엣지에서

  1. 오른쪽 위 다운로드 아이콘을 누릅니다.
  2. 막힌 파일 옆 ⋯ 또는 ∨ 를 누릅니다.
  3. 유지 또는 계속 를 선택하면 받아집니다.

그래도 안 되면 압축 파일로

zip은 대부분 차단 없이 받아집니다. 받은 뒤 압축을 풀면 같은 설치 파일이 나옵니다.

zip으로 내려받기

설치하기

  1. 받은 ojip-0.1.0-Setup.exe 를 두 번 누릅니다.
  2. “Windows의 PC 보호” 파란 창이 뜨면 추가 정보 → 실행 을 누릅니다. 이 창도 서명이 없어서 나오는 안내입니다.
  3. 설치 위치를 확인하고 설치 를 누르면 끝납니다.

처음 켰을 때

후원자에게 보내드린 이용권 키를 입력하면 바로 시작됩니다. 키는 OJIP-XXXX-XXXX 모양이고, 한 번 넣으면 다음부터는 묻지 않습니다.

오집!은 본인의 AI API 키를 연결해 쓰는 방식입니다. 설정 화면에서 사용하실 AI를 고르고 키를 넣어 주세요.
